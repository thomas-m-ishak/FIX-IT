# Fix It - Home Services Booking Platform

A web platform that connects clients with certified technicians (such as plumbers and carpenters) for home repair services, with a booking and scheduling workflow and a post-service rating and review system.

Team project, Assiut University, Business Information Systems (BIS).

## Features

- Booking and scheduling of home services with certified technicians
- Post-service rating and review system, so clients can evaluate technicians after each job
- Quality control and accountability through client feedback

## Tech Stack

- C#
- .NET
- SQL Server
- HTML, CSS, JavaScript

## Getting Started

1. Clone the repository.
2. Open `FIX IT.sln` in Visual Studio.
3. Update the SQL Server connection string in the project's configuration file to match your machine.
4. Create the database, then press F5 to run the project.
